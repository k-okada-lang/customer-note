# お客様ノート（デモ版）

ナイト業態向けの、QRチェックイン付き顧客管理システムのデモ画面です。
現在は Claude の Artifact 上で動くデモで、本番は XServer に構築する予定です。

## 主な機能

- ホーム画面（本日の来店数、各機能へのタイル、お知らせ）
- お客様の登録・編集・削除（会社名、部署・役職、誕生日、特徴、メモ、VIP、紹介者）
- お客様の写真、名刺（表・裏）の保存。スマートフォンではカメラで撮影可
- QRコードの発行、カード画像（PNG）の保存、A4印刷用ファイルの出力
- QRコードの読み取り（撮影した写真・画像から）とチェックイン
- 来店処理：チェックイン、来店ごとのお会計・注文・卓番号・人数・担当黒服・キャストと指名種別
- 未入力の来店は黄色で表示。お会計を入力すると「退店済み」
- 来店履歴、今月の誕生日、30日以上ご無沙汰、VIP、入力待ちの絞り込み
- キャスト・黒服の登録
- CSV出力
- デモ用ログインと管理者の追加（何を入力してもログインできます）

名刺のOCRは入れていません。

## デモの公開URL（GitHub Pages）

https://k-okada-lang.github.io/customer-note/

- データは、開いた人のブラウザの中（localStorage）にだけ保存されます。ほかの人や端末とは共有されません。
- 初回に、架空のお客様10名とキャスト・黒服5名が入ります。
- 画面を変えたら `node build.mjs` を実行して `docs/` を作り直し、コミットして送信すると反映されます。

## Artifact 上での動作

`index.html` は Artifact の次の機能を使います。

- `db`：お客様・来店・スタッフ・管理者・店舗名の保存（読み書きともコントリビューター以上）
- `assets`：写真と名刺画像の保存
- `downloads`：CSV、カード画像、印刷用ファイルの保存
- `user`：書き込み権限の確認

保存先の構成は次のとおりです。

- `customers/{id}`：お客様。来店の集計（来店回数、未入力件数、最終来店など）も持ちます
- `customers/{id}/visits/{id}`：来店
- `staff/{id}`：キャスト・黒服
- `admins/{id}`：デモ用の管理者
- `settings/shop`：店舗名

営業日は朝6時で切り替わります（`DAY_START_HOUR`）。

## テスト

```
npm install
npm test
```

保存先などをテスト用の仮の仕組みに差し替え、Chromium で画面を自動操作します。
実機のカメラ、実際のファイル保存と印刷、iPhone の Safari は対象外です。

## 注意

- ログインはデモ用の見た目の再現で、データの保護にはなりません。本番ではサーバー側の認証に置き換えます。
- 本番用のパスワードや実在のお客様の情報は入れないでください。
- 同じお客様を2人が同時に編集すると、後から保存した内容で上書きされます。
